# Service-level objectives

These initial objectives make readiness measurable while remaining
proportionate to the demonstration.

| Dimension | Initial objective |
|---|---|
| Freshness | Data available by 07:00 on at least 98% of scheduled business days |
| Conservation | Every Bronze input row is current, superseded, or quarantined |
| Repeatability | Reprocessing the same batches creates no unintended current duplicates |
| Recovery | A failed candidate release leaves the previous certified output available |
| Response | Material failures acknowledged within 30 minutes during support hours |
| Restoration | Recovery or a status communication within two hours |
| Traceability | Every governed row retains source-system, source-record and run provenance |
| Release | Missing classification, lifecycle or validation ownership blocks promotion |

Targets will be reviewed after sufficient operational history exists. They are
service objectives, not claims about current production performance.
