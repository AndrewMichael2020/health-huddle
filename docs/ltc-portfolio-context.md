# LTC portfolio context

The fictional LTC portfolio reconstructs a longitudinal access journey from
acute encounters and community-service activity. Meditech-inspired data supplies
encounter, location, transfer and discharge information. Civica PARIS-inspired
data supplies referrals, assessments, programs and status history.

The modernization must preserve source distinctions while allowing governed
connections across systems. A single row count cannot establish correctness:
late corrections, repeated events, unmapped codes and ambiguous identifiers can
all produce plausible totals with incorrect journeys.

The six-person BI Analytics team owns analytical interpretation, validation and
ticket definition. Data Engineering, Systems, and Privacy/Security own work that
requires changes within their respective domains.
