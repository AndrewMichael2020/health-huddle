# Demonstration provenance

Skagit Health Authority, its people, identifiers, records, tickets, counts, and
source schemas are created for this demonstration. The source maps illustrate
healthcare data-engineering problems without representing actual Meditech or
Civica PARIS schemas. No Fraser Health data, code, credentials, or operational
configuration belongs in this repository.

The two source batches are generated deterministically from synthetic inputs.
The local pipeline simulates the behaviours needed to discuss Microsoft Fabric
ingestion, standardization, reconciliation, quarantine, lineage, service
objectives, and release gates; it does not claim to execute in a Fabric tenant.

The huddle is a deterministic production. Its transcript, action ledger,
Project states, voice assignments, human handoffs, reaction timing, and render
plan were validated before synthesis. ElevenLabs produced separate clips for
each speaking turn. Pillow produced the visual composition, and FFmpeg produced
the synchronized audio and final H.264/AAC video. GitHub Actions retained the
validation evidence and media manifests.

The final video contains agent-generated recommendations and synthetic data.
It keeps privacy, source meaning, product service objectives, and release
approval with explicitly named human roles.
